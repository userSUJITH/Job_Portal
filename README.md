# O2H Job Portal

A responsive Job Portal application built using HTML, CSS, and JavaScript. The application allows users to browse job listings, search jobs, filter by company and location, and apply for jobs.

---

## Features

- Home Page
- Jobs Page
- Contact Page
- Search Functionality
- Company Filter
- Location Filter
- Pagination
- Responsive UI
- Fetch Data from API
- Dark Mode
- Loading Skeletons
- Error Handling

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Local Storage

## Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/o2h-job-portal.git
```

### 2. Navigate to the Project Directory

```bash
cd o2h-job-portal
```

### 3. Open the Project

Since this project uses only HTML, CSS, and JavaScript, no additional installation is required.

Open:

```
index.html
```

in your browser.

---

## Running with VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.

The application will run locally at:

```
http://127.0.0.1:5500
```

## API Used

Job data is fetched from:

```
https://api.joinrise.io/api/v1/jobs/public?page=1&limit=50
```
